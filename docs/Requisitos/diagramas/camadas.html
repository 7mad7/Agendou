Arquitetura em camadas do Agendou

1. Apresentação
Next.js App Router, React 19, Tailwind
Telas mobile-first em src/app e componentes em src/components. Validação visual dos formulários com React Hook Form + Zod.
chama
2. Aplicação
Server Actions e Route Handlers
Casos de uso em src/actions (auth, merchant, services, availability, discovery, booking). A API REST em src/app/api reaproveita as mesmas actions. middleware.ts protege o painel.
usa
3. Domínio e regras
TypeScript puro
Motor de horários availability-engine, esquemas de validação validations, sessão assinada session e formatadores.
persiste por
4. Persistência
Prisma ORM
Cliente Prisma em src/lib/prisma.ts, esquema em db/schema.prisma e migrações versionadas em db/migrations.
SQL
5. Dados
PostgreSQL 16
Tabelas User, ClientProfile, MerchantProfile, Service, MerchantAvailability e Booking, com restrições de unicidade e chaves estrangeiras.
